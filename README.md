## 🔄 전체 흐름

이 시스템은 세 개의 파트가 순서대로 연결되어 돌아갑니다.

**파트 A → 파트 B → 파트 C** 순서로 매달 자동 실행됩니다.

### 파트 A — 날씨 예보

매달 시장이 얼마나 위험한지를 0점에서 10점 사이 숫자로 측정합니다.
VIX, PMI, 금리차, 신용 스프레드 같은 지표들을 종합해서
리스크 점수 하나를 산출하고 B와 C에 넘겨줍니다.

### 파트 B — 자산 배분 설계

A가 넘겨준 리스크 점수를 바탕으로
9개 자산에 돈을 얼마씩 나눌지 수학적으로 계산합니다.
점수가 높을수록 위험 자산 비중은 줄고 안전 자산 비중은 늘어납니다.

### 파트 C — 미래 시뮬레이션

B가 계산한 비중대로 매달 160만원씩 투자했을 때
5년 후 잔고가 어떻게 될지 1만 번 시뮬레이션합니다.
최종적으로 1억 5,000만원 달성 확률을 계산합니다.

## 👤 파트 A 담당자 역할

### 한 줄 요약

시장 데이터를 수집하고, 지금이 안전한지 위험한지 점수로 표현하는 역할

### 가져와야 하는 데이터

| 데이터 | 출처 | 라이브러리 |
| --- | --- | --- |
| 국내 주식 5종목 | 한국거래소 | pykrx |
| 해외 주식 4종목 | 미국 거래소 | yfinance |
| 원달러 환율 | 한국은행 API | - |
| VIX, SKEW, PCR, MOVE | CBOE | - |
| PMI, 금리차, CPI, HY스프레드 | FRED API | pandas_datareader |
| OECD CLI | OECD API | - |

### 리스크 점수 계산 방법

점수는 세 그룹으로 나눠서 가중 합산합니다.

**선행 그룹 (40% 비중)** — 미래를 미리 보여주는 지표

| 지표 | 경계 (1점) | 위험 (2점) |
| --- | --- | --- |
| OECD CLI | 100 하회+하락 | 급격한 하락 |
| ISM PMI | 50 하회 | 2개월 이상 지속 |
| 장단기 금리차 | 역전 발생 | — |
| CPI | 예상치 상회 | 둔화 멈춤+상승 지속 |

**동행 그룹 (35% 비중)** — 지금 당장의 공포를 보여주는 지표

| 지표 | 경계 (1점) | 위험 (2점) |
| --- | --- | --- |
| VIX | 20~30 | 30+ |
| SKEW | 130~140 | 140+ |
| VIX 백워데이션 | 5~7거래일 | 1주+ |
| PCR | 0.6↓ 과열 | 1.1~1.3 공포 |

**후행 그룹 (25% 비중)** — 위기가 진행 중임을 확인하는 지표

| 지표 | 경계 (1점) | 위험 (2점) |
| --- | --- | --- |
| HY 스프레드 | 5~6% | 7%+ |
| MOVE 지수 | 120~150 | 150+ |
| FRA-OIS | 50~100bp | 100bp+ |
| AA- 회사채 | 80bp | 150bp+ |

### 최종 출력물

```python
price_data   # 9개 자산 원화 환산 일별 수익률
risk_score   # 0~10 숫자, 매월 갱신
```

### 주의사항

백테스팅 시 미래 데이터를 절대 사용하면 안 됩니다.
2020년 3월 점수를 계산할 때는 2020년 3월 이전 데이터만 사용해야 합니다.
이를 어기면 전체 결과가 실제보다 좋게 나와 신뢰도가 무너집니다.

## 👤 파트 B 담당자 역할

### 한 줄 요약

A의 데이터를 받아서 9개 자산의 최적 투자 비중을 수학적으로 계산하는 역할

### 작업 순서

**Step 1. DCC-GARCH 공분산 추정**
자산들이 서로 얼마나 같이 움직이는지 계산합니다.
최근 데이터에 더 큰 가중치를 주는 방법입니다.
arch 라이브러리를 사용합니다.

**Step 2. Ledoit-Wolf Shrinkage**
Step 1에서 나온 행렬을 수학적으로 안정화시킵니다.
이 과정이 없으면 최적화가 오류를 내거나
한 종목에 비중이 100% 몰리는 말이 안 되는 결과가 나옵니다.

**Step 3. 리스크 패리티 역최적화**
블랙-리터만의 기준값을 만들기 위해
모든 자산이 동일한 위험을 부담하는 비중을 계산합니다.

**Step 4. 블랙-리터만 + Idzorek**
시장 기준값에 투자 확신도를 수학적으로 결합합니다.

초기 확신도 설정:

- AI 슈퍼사이클 (SOL ETF, PLTR, VRT, 신성이엔지): 75%
- ESS 에너지 (SK이터닉스): 65%
- 구리 공급 부족 (FCX): 60%
- 인플레 헤지 (KOSEF 물가채): 55%
- 배당 레버리지 (유안타증권): 50%

**Step 5. 리스크 점수 반영**

### 최종 출력물

```python
optimal_weights    # 9개 자산 + 현금 목표 비중
expected_returns   # 각 자산의 기대수익률
```

## 👤 파트 C 담당자 역할

### 한 줄 요약

A와 B의 결과물을 받아서 5년 시뮬레이션을 돌리고
1억 5,000만원 달성 확률을 계산하는 역할

### 거래비용 반영

| 항목 | 비용 |
| --- | --- |
| 국내 주식 매수 수수료 | 0.015% |
| 국내 주식 매도 거래세 | 0.18% |
| 해외 주식 환전비용 | 0.5% |
| 해외 주식 수수료 | 0.25% |
| 리밸런싱 발생 시 추가 | 0.15~0.3% |

### 블록 부트스트래핑

정규분포 대신 과거 실제 데이터를 블록째로 뽑아서
미래 경로를 구성합니다.

### 글라이드 패스

| 잔고 구간 | 행동 |
| --- | --- |
| ~1억 500만원 (70% 미만) | 공격적 비중 유지 |
| 1억 500만원~1억 3,500만원 | PLTR, VRT, 신성이엔지 단계 축소 |
| 1억 3,500만원 이상 (90%+) | AI 테마 전체 절반 축소, 물가채·현금 확대 |
| 리스크 점수 7점+ | 잔고 무관, 즉시 방어 모드 |

### 최종 출력물

```python
prob_achieve       # 1억 5천만원 달성 확률
median_final       # 중앙값 최종 잔고
percentile_5       # 최악 시나리오 (하위 5%)
percentile_95      # 최선 시나리오 (상위 5%)
monthly_chart      # 월별 잔고 분포 차트
```
